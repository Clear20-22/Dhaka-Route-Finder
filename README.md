# Dhaka Smart Route Finder

Context-aware, profile-based route finding on Dhaka's real road network, comparing seven search algorithms (BFS, DFS, IDS, UCS, Bidirectional, Greedy, A\*) under traffic, rain, blockade and safety conditions.
